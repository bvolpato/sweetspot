Is it the Wi-Fi or the ISP?

sweetspot pings your router and the internet at the same time. If the first hop is bad, the problem is in your home. If only the second hop is bad, you can stop moving the router.

Hand it to your agent.

Every command prints JSON, with exit codes a script can trust. Take a snapshot, change one thing, take another, and compare.

# 1. Measure
sweetspot diagnose --speed --scan --out before.json --json

# 2. Change one router setting, then measure again
sweetspot diagnose --speed --out after.json --json

# 3. Compare
sweetspot diff before.json after.json --format markdown

# Fail a script when a spot scores below 80 (exit code 3)
sweetspot diagnose --fail-below 80 --json
